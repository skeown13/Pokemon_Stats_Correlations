# Pokemon_Stats_Correlations
A Jupyter Notebook that goes through correlations of Pokemon's Weights vs their Attack Power and their Defensive Abilities. 

## Problem
When it comes to Pokemon, does an increase in weight mean an increase in attack power or defensive abilities?

## Data Source
https://www.kaggle.com/datasets/shreyashautomation/pokemon-stats-dataset

## Findings
For both the comparisons of the Weight of a pokemon to its Attack Power and its Defensive Abilities, there is a slight positive correlation. The trend line does move in the upwards direction. Taking a look at all the scatter plots, it is a weak correlation, but it is there. 

If a person were to want to know more specifics in order to choose the strongest or most resilient pokemon to add to their team, more research would need to be done. Basing that decision solely on weight would not guarantee expected results.  

## How to Run
Download Code. Make sure that you have python, pandas, matplotlib, and seaborn installed. Run the Notebook.
